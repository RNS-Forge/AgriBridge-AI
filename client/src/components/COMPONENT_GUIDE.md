# UI Component Library Guide\n\nComprehensive reusable component system for AgriBridge-AI. All components follow accessibility standards (WCAG 2.1 AA), use TailwindCSS, and maintain consistent design language.\n\n## Principles\n\n- **Single Responsibility**: Each component does one thing well\n- **Composability**: Components can be nested and combined\n- **Accessibility**: ARIA attributes, keyboard navigation, screen reader support\n- **Themable**: Colors/sizes via props, TailwindCSS variants\n- **Forwardable**: All components use `forwardRef` for external access\n\n---\n\n## Button\n\n```tsx\nimport { Button } from '@/components';\n\n<Button variant=\"primary\" size=\"md\" loading={false}>\n  Click me\n</Button>\n```\n\n### Props\n\n- `variant`: 'primary' | 'secondary' | 'outline' | 'danger' | 'ghost'\n- `size`: 'sm' | 'md' | 'lg'\n- `disabled`: boolean\n- `loading`: boolean (shows spinner)\n- `fullWidth`: boolean (default: true)\n- `leftIcon`: ReactNode\n- `rightIcon`: ReactNode\n- `type`: 'button' | 'submit' | 'reset'\n- `aria-label`: string (for icon-only buttons)\n\n---\n\n## Card\n\n```tsx\nimport { Card, CardHeader, CardTitle, CardContent, CardFooter } from '@/components';\n\n<Card variant=\"elevated\" title=\"My Card\">\n  <CardContent>Content here</CardContent>\n  <CardFooter>Footer content</CardFooter>\n</Card>\n```\n\n### Props\n\n- `variant`: 'default' | 'elevated' | 'outlined' | 'gradient'\n- `padding`: 'none' | 'sm' | 'md' | 'lg'\n- `title`: string\n- `description`: string\n- `onClick`: () => void (makes card interactive)\n- `as`: 'div' | 'article' | 'section'\n\n---\n\n## Input\n\n```tsx\nimport { Input } from '@/components';\n\n<Input\n  id=\"email\"\n  label=\"Email\"\n  type=\"email\"\n  value={email}\n  onChange={(e) => setEmail(e.target.value)}\n  icon={<MailIcon />}\n  error={errors.email}\n  required\n/>\n```\n\n### Props\n\n- `id`: string (required)\n- `label`: string\n- `type`: 'text' | 'email' | 'password' | 'number' | 'search'\n- `value`: string\n- `onChange`: (e) => void\n- `placeholder`: string\n- `icon`: ReactNode (left icon)\n- `rightIcon`: ReactNode\n- `error`: string (displays below input)\n- `disabled`: boolean\n- `required`: boolean\n\n---\n\n## TextArea\n\n```tsx\nimport { TextArea } from '@/components';\n\n<TextArea\n  id=\"description\"\n  label=\"Description\"\n  value={text}\n  onChange={(e) => setText(e.target.value)}\n  maxLength={500}\n  rows={4}\n/>\n```\n\n### Props\n\n- Same as Input + `maxLength`, `rows`\n- Shows character count if `maxLength` provided\n\n---\n\n## Modal\n\n```tsx\nimport { Modal } from '@/components';\n\nconst [open, setOpen] = useState(false);\n\n<Modal\n  isOpen={open}\n  onClose={() => setOpen(false)}\n  title=\"Delete Item?\"\n  size=\"md\"\n>\n  <p>Are you sure?</p>\n</Modal>\n```\n\n### Props\n\n- `isOpen`: boolean\n- `onClose`: () => void\n- `title`: string\n- `description`: string\n- `size`: 'sm' | 'md' | 'lg' | 'xl'\n- `closeOnEsc`: boolean (default: true)\n- `closeOnBackdropClick`: boolean (default: true)\n\n### Features\n\n- Focus trap (first focusable element receives focus)\n- Escape key closes\n- Backdrop click closes\n- Prevents scroll on body\n\n---\n\n## Badge\n\n```tsx\nimport { Badge } from '@/components';\n\n<Badge variant=\"primary\" size=\"md\" icon={<CheckIcon />}>\n  Active\n</Badge>\n```\n\n### Props\n\n- `variant`: 'default' | 'primary' | 'warning' | 'danger' | 'info'\n- `size`: 'sm' | 'md'\n- `icon`: ReactNode\n\n---\n\n## Avatar\n\n```tsx\nimport { Avatar } from '@/components';\n\n<Avatar src=\"/avatar.jpg\" alt=\"John\" size=\"md\" />\n<Avatar initials=\"JD\" size=\"lg\" /> {/* Fallback */}\n```\n\n### Props\n\n- `src`: string (image URL)\n- `alt`: string\n- `initials`: string (fallback to image)\n- `size`: 'xs' | 'sm' | 'md' | 'lg' | 'xl'\n\n---\n\n## Table\n\n```tsx\nimport { Table, TableHead, TableBody, TableRow, TableHeader, TableCell } from '@/components';\n\n<Table striped hoverable>\n  <TableHead>\n    <TableRow>\n      <TableHeader>Name</TableHeader>\n      <TableHeader>Email</TableHeader>\n    </TableRow>\n  </TableHead>\n  <TableBody>\n    <TableRow>\n      <TableCell>John</TableCell>\n      <TableCell>john@example.com</TableCell>\n    </TableRow>\n  </TableBody>\n</Table>\n```\n\n### Features\n\n- Striped rows (alternating bg)\n- Hover effects\n- Responsive wrapper\n- Semantic HTML (`<thead>`, `<tbody>`, `scope=\"col\"`)\n\n---\n\n## Pagination\n\n```tsx\nimport { Pagination } from '@/components';\n\nconst [page, setPage] = useState(1);\n\n<Pagination\n  currentPage={page}\n  totalPages={10}\n  onPageChange={setPage}\n  maxButtons={5}\n/>\n```\n\n### Props\n\n- `currentPage`: number\n- `totalPages`: number\n- `onPageChange`: (page: number) => void\n- `maxButtons`: number (default: 5)\n\n---\n\n## Loader\n\n```tsx\nimport { Loader } from '@/components';\n\n<Loader size=\"md\" text=\"Loading...\" fullHeight />\n```\n\n### Props\n\n- `size`: 'sm' | 'md' | 'lg'\n- `text`: string\n- `fullHeight`: boolean (min-h-screen)\n\n---\n\n## EmptyState\n\n```tsx\nimport { EmptyState } from '@/components';\n\n<EmptyState\n  icon=\"📭\"\n  title=\"No items found\"\n  description=\"Try adjusting your filters\"\n  action={<Button>Clear filters</Button>}\n/>\n```\n\n### Props\n\n- `icon`: ReactNode | string (emoji)\n- `title`: string\n- `description`: string\n- `action`: ReactNode\n\n---\n\n## ErrorState\n\n```tsx\nimport { ErrorState } from '@/components';\n\n<ErrorState\n  title=\"Failed to load\"\n  message=\"Something went wrong\"\n  details=\"Error code: 500\"\n  onRetry={() => refetch()}\n/>\n```\n\n### Props\n\n- `title`: string\n- `message`: string\n- `details`: string (error details)\n- `onRetry`: () => void\n- `action`: ReactNode\n\n---\n\n## Accessibility Checklist\n\n✅ All buttons: `aria-label` for icon-only\n✅ All inputs: `aria-invalid`, `aria-describedby` for errors\n✅ Modal: `role=\"dialog\"`, `aria-modal=\"true\"`, focus trap\n✅ Table: `<thead>`, `<tbody>`, `scope=\"col\"`\n✅ Pagination: `aria-current=\"page\"`, `aria-disabled`\n✅ Loader: `role=\"status\"`, `aria-live=\"polite\"`\n✅ EmptyState: `role=\"status\"`\n✅ ErrorState: `role=\"alert\"`\n✅ All: keyboard navigation, focus visible\n\n---\n\n## Import Examples\n\n```tsx\n// Individual imports (recommended for tree-shaking)\nimport { Button, Card, Input } from '@/components';\n\n// Wildcard imports\nimport * as UI from '@/components';\nconst MyButton = UI.Button;\n\n// Specific UI imports\nimport { Button, Badge } from '@/components/ui';\nimport { FormField } from '@/components/forms';\n```\n\n---\n\n## Component Status\n\n- [x] Button (5 variants)\n- [x] Card (4 inputRef = useRef<HTMLInputElement>(null);\n   <Input ref={inputRef} />\n   ```\n\n2. **Combine components for complex UIs**\n   ```tsx\n   <Card>\n    <CardHeader><CardTitle>Users</CardTitle></CardHeader>\n    <CardContent>\n      <Table>...</Table>\n      <Pagination />\n    </CardContent>\n  </Card>\n   ```\n\n3. **Use aria-labels for clarity**\n   ```tsx\n   <Button aria-label=\"Close dialog\" onClick={onClose}>✕</Button>\n   ```\n\n4. **Test with keyboard navigation**\n   - Tab through all interactive elements\n   - Escape should close modals\n   - Enter should activate buttons\n\n---\n\n## Color System\n\nAll components use the existing design language:\n\n- **Primary**: Emerald (emerald-500, emerald-600)\n- **Secondary**: Slate (slate-700, slate-800)\n- **Success**: Emerald shades\n- **Warning**: Amber shades\n- **Danger**: Red shades\n- **Info**: Blue shades\n- **Disabled**: Reduced opacity + cursor-not-allowed\n\nColors are defined in `tailwind.config.js` and can be customized globally.\n
