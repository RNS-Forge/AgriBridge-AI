# UI Component Library\n\n## Overview\n\nA production-ready, accessible, reusable component library for AgriBridge-AI built with React, TypeScript, and TailwindCSS.\n\n**15 Core Components** | **Fully Accessible (WCAG 2.1 AA)** | **Zero External Dependencies** | **Tree-shakeable**\n\n---\n\n## Quick Start\n\n### Installation\n\nAll components are colocated in this directory. Simply import them:\n\n```tsx\nimport { Button, Card, Input, Modal } from '@/components';\n```\n\n### Basic Usage\n\n```tsx\nimport { Button, Card, CardContent, Input } from '@/components';\nimport { useState } from 'react';\n\nexport function MyForm() {\n  const [name, setName] = useState('');\n  const [loading, setLoading] = useState(false);\n\n  const handleSubmit = async () => {\n    setLoading(true);\n    // Call API...\n    setLoading(false);\n  };\n\n  return (\n    <Card>\n      <CardContent className=\"space-y-4\">\n        <Input\n          id=\"name\"\n          label=\"Full Name\"\n          value={name}\n          onChange={(e) => setName(e.target.value)}\n        />\n        <Button loading={loading} onClick={handleSubmit}>\n          Submit\n        </Button>\n      </CardContent>\n    </Card>\n  );\n}\n```\n\n---\n\n## Component Inventory\n\n### Core Components\n\n1. **Button** — Interactive element with 5 variants and 3 sizes\n2. **Card** — Container with 4 variants and subcomponents\n3. **Input** — Text input with validation and icons\n4. **TextArea** — Multi-line text with character counter\n5. **Modal** — Dialog with focus trap and backdrop control\n6. **Badge** — Semantic label in 5 color variants\n7. **Avatar** — Profile image with initials fallback\n8. **Table** — Data table with semantic HTML\n9. **Pagination** — Smart page navigation\n10. **Loader** — Loading spinner with text\n11. **EmptyState** — Placeholder when no data\n12. **ErrorState** — Error display with retry\n13. **ErrorBanner** — Inline error notification\n14. **Toast** — Temporary notification message\n15. **FormField** — Text input wrapper (legacy, use Input instead)\n16. **SocialButton** — Social login button\n\n### Composition\n\nCard subcomponents:\n- `CardHeader`\n- `CardTitle`\n- `CardDescription`\n- `CardContent`\n- `CardFooter`\n\nTable subcomponents:\n- `TableHead`\n- `TableBody`\n- `TableRow`\n- `TableHeader`\n- `TableCell`\n\n---\n\n## Key Features\n\n### 🎨 Design Language\n\n- **Dark theme** with slate backgrounds (slate-900, slate-950)\n- **Emerald/Teal accents** for primary actions\n- **Semantic colors** for variants (warning=amber, danger=red, info=blue)\n- **Smooth transitions** with duration-300 timing\n- **Backdrop blur** for modals and elevated surfaces\n\n### ♿ Accessibility\n\n✅ **WCAG 2.1 Level AA Compliant**\n\n- Semantic HTML (`<button>`, `<label>`, `<table>`)\n- ARIA attributes (`aria-label`, `aria-invalid`, `aria-live`)\n- Keyboard navigation (Tab, Enter, Escape)\n- Focus management (visible `:focus-ring` states)\n- Screen reader support (role, aria-describedby)\n- Color contrast ratios ≥ 4.5:1\n\n### 🔧 Developer Experience\n\n- **TypeScript** fully typed\n- **forwardRef** on all components for DOM access\n- **Composition** over prop drilling (use subcomponents)\n- **Barrel exports** for clean imports\n- **Tailwind utilities** instead of CSS files (no duplication)\n- **Zero dependencies** (React + TailwindCSS only)\n\n### 📦 Size & Performance\n\n- **Tree-shakeable** — unused components don't ship\n- **No CSS files** — all TailwindCSS utilities\n- **No icons** — SVG inline when needed\n- **~2KB gzipped** per component (avg)\n\n---\n\n## Design System\n\n### Spacing\n\n- `p-4` / `p-6` / `p-8` — standard card padding\n- `gap-2` / `gap-3` / `gap-4` — component spacing\n- `mb-4` / `mt-6` — section spacing\n\n### Typography\n\n- `text-xs` — labels, helpers\n- `text-sm` — body text\n- `text-base` — section headings\n- `text-lg` — card titles\n- `font-semibold` — button text\n- `font-bold` — main headings\n\n### Colors\n\n**Interactive States:**\n- Default: slate-700 border, slate-950 bg\n- Focus: emerald-500 ring, emerald-500/60 border\n- Hover: opacity-90, translate-y-[-2px]\n- Disabled: opacity-50, cursor-not-allowed\n\n**Semantic:**\n- Success: emerald-400, emerald-950/50 bg\n- Warning: amber-400, amber-950/50 bg\n- Error: red-400, red-950/30 bg\n- Info: blue-400, blue-950/50 bg\n\n### Breakpoints\n\nUse Tailwind's responsive prefixes:\n\n```tsx\n<div className=\"text-sm md:text-base lg:text-lg\">\n  Responsive Ensure `tailwind.config.js` includes `client/src/**/*.{tsx,ts}`\n2. Check that Tailwind CSS is imported in your app\n\n### Styles not applying\n\n1. Use Tailwind classes directly (no CSS files)\n2. Check class name syntax (no hyphens in class values)\n3. Verify `className` prop is spelled correctly\n\n### Accessibility warnings\n\n1. Always provide `aria-label` for icon-only buttons\n2. Use `htmlFor` on labels and match input `id`\n3. Provide `aria-describedby` when error messages present\n\n---\n\n## Contributing\n\nWhen adding new components:\n\n1.
